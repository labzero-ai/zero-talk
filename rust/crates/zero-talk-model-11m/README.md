# Zero Talk 11M model files

The model and English text front-end files of [Zero Talk 11M](https://labzero.ai/zero-talk-11m/), compiled into a Rust
crate as byte slices. The crate also provides each file's size and SHA-256 hash.

Use the [zero-talk crate](https://crates.io/crates/zero-talk) to load the voice, speak text and stream audio. It embeds
these files by default.

Source: [labzero-ai/zero-talk](https://github.com/labzero-ai/zero-talk).
